Reusable Elementor widgets and a private project brief for WordPress sites. The plugin can run with any theme. Elementor Free is required for the widgets; the project planner shortcode works without Elementor.

== Features ==
* Project Planner widget and [undo_project_planner] shortcode. The form creates a text download in the visitor's browser. It sends and stores no answers.
* Service Card widget for an editorial services list.
* Project Invitation widget for a compact call to action.
* English and Persian translation catalogs, RTL-aware styling, keyboard focus, and reduced-motion support.
* GitHub Releases dashboard updates with SHA-256 verification of the ZIP.

== Installation ==
Upload undo-elements-0.1.0.zip in Plugins > Add New > Upload Plugin, then activate. Install and activate Elementor Free to see the UNDO Elements widget category in the editor. The UNDO theme uses the plugin planner automatically on its native Home page. The theme retains its own planner when this plugin is inactive.

== Privacy ==
The project planner does not submit answers to a server. The downloadable text is generated locally in the browser. Future submission or storage features require a separate opt-in and privacy review.
