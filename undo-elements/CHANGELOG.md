# UNDO Elements changelog

## [0.1.1] - 2026-11-14

- The planner brief follows Polylang's active language when that content translation plugin is present.
- Improved Persian heading rhythm and RTL arrow direction. Name and goal fields now choose text direction from the visitor's input.

## [0.1.0] - 2026-11-14

- Released the Project Planner, Service Card, and Project Invitation widgets for Elementor Free.
- Added `[undo_project_planner]` for sites without Elementor and native UNDO Home integration with a theme fallback.
- Added English and Persian PO/MO catalogs, RTL-aware CSS, accessible form labels and focus states, and a browser-only brief download.
- Added independent GitHub Release ZIP updates with SHA-256 verification and in-dashboard release details.
