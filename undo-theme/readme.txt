A Persian-first, English-capable agency theme with RTL styles, Elementor-compatible templates, and a standalone theme settings dashboard.

== Installation ==
Upload the theme ZIP under Appearance > Themes, activate it, then open UNDO Theme Settings in the main admin menu.

== Notes ==
Elementor is optional. Elementor Pro is needed for Theme Builder location replacement. User-created pages and posts need a multilingual content solution for translation. This package is a pre-release until tested on a WordPress staging site.
