# UNDO Elementor starters

`home-en.json`, `home-fa.json`, `blog-page-en.json`, and `blog-page-fa.json` are editable Elementor Free page templates. With Elementor active, UNDO creates one published page from each template on the first admin load. Choose the matching Home and Blog pair under Settings > Reading. The theme never changes existing Reading settings. If Elementor is inactive, the native Home and blog remain.

The matching `header-*.json`, `footer-*.json`, and `blog-archive-*.json` files require Elementor Pro Theme Builder. Import each site part, review its widgets, choose a WordPress menu for the header Nav Menu widget, then set display conditions. The blog starter uses the dynamic Archive Posts widget. The footer starter uses `[undo_footer_widgets]` to show populated footer widget areas from Appearance > Widgets; remove that Shortcode widget if you prefer Elementor-only footer content.

Elementor content is stored in WordPress, not in the theme directory. Theme updates never overwrite created or imported templates or pages. The Blog Page uses `[undo_blog_posts]` for the live post listing, because WordPress normally ignores the selected Posts page body. The theme's built-in templates remain available until replacements are assigned and when Elementor is disabled. The English and Persian files are separate content examples; use a multilingual content plugin for production bilingual page routing.
