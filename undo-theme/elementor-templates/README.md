# UNDO Elementor starters

`home-en.json` and `home-fa.json` are editable Elementor Free page templates. Import one into a WordPress page, publish it, and assign that page as the Homepage under Settings > Reading.

The matching `header-*.json`, `footer-*.json`, and `blog-archive-*.json` files require Elementor Pro Theme Builder. Import each site part, review its widgets, choose a WordPress menu for the header Nav Menu widget, then set display conditions. The blog starter uses the dynamic Archive Posts widget. The footer starter uses `[undo_footer_widgets]` to show populated footer widget areas from Appearance > Widgets; remove that Shortcode widget if you prefer Elementor-only footer content.

Elementor content is stored in WordPress, not in the theme directory. Theme updates never overwrite imported templates or pages. The theme's built-in templates remain available until replacements are assigned and when Elementor is disabled. The English and Persian files are separate content examples; the theme switcher does not automatically translate Elementor-authored content. Use a multilingual content plugin for production bilingual page routing.
